# * Calculadora Da Média De Alunos*

 Automotização de calculo sobre a media de alunos de uma instituição, feito a proposito de apresentar conhecimento de Python em meu GitHub.

# * Apresentação 

 Essa e uma aplicação com o objetico de facilitar o processo do professor de calcular a média de seu aluno.

# * Tecnologia Usadas * 

 Nessa aplicação foi utilizado as tecnologias:

 - Python (3.13.2)

# * Formas de executar essa aplicação *

 Podemos executar essa aplicação atraves de uma IDE reponsavel como o VsCode ou um compilador pela Web programiz.com 

# *Como foi constituida a aplicação*

 essa aplicação foi dividida em duas partes o 

    1. app.py
     
     seria a aplicação em sua forma onde foi desenvolvida em Python um simples Script feito de forma rapida, porém, eficiente 

    2. README.md

     A documentação e apresentação da aplicação onde desenvolo a apresentação do que a aplicação resolve e como foi o processo de criação da aplicação e detalhes sobre a aplicação.

# * Funcinalidades * 

 A apçicação funciona da seguinte forma:

  Foi criado uma função chamada calcular_media onde nela contém a formula do calculo da media, logo após vem o sistema de print e input para que o usuario consiga visualizar a pergunta da primeira e segunda nota e com isso a aplicação consegui realizar a entrada dos dados. 

# * Resumo * 

 Uma aplicação com conceitos basicos do Python com intuito de automatizar e contribuir com professores para o calculo da média de alunos em vasta escala.
